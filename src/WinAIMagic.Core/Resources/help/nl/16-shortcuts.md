| Toets | Wat |
|---|---|
| Ctrl+N | Nieuw gesprek |
| Enter | Bericht versturen |
| Shift+Enter | Nieuwe regel in je bericht |
| Ctrl+V | Plakken, ook afbeeldingen en schermafbeeldingen |
| F1 | De hulp bij het scherm dat open is |
| Enter op een goedkeuringskaart | Toestaan |
| Esc op een goedkeuringskaart | Weigeren |

Een schermafbeelding maak je met Windows-toets+Shift+S; plak hem daarna met Ctrl+V in de chat.
