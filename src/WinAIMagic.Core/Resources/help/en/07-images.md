Describe under **Beeld** what you want to see. FLUX.2 Klein makes the image on this PC; earlier images are below it.

## Tips
- An **English** description works best.
- **Improve with web**: the fast model first writes a better English description and looks up what something looks like when needed. Every step is shown, with the model that does it.
- Choose the size at the top. On a PC with little VRAM the app chooses a smaller size.

## Where are they?
In `Pictures\WinAIMagic` (also when that folder points to OneDrive), with the description in a file beside each image.

> The chat model on the graphics card stops first, so FLUX has the card. The fast model runs on the processor and may stay when the RAM is large enough.
