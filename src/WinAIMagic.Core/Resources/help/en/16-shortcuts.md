| Key | What |
|---|---|
| Ctrl+N | New conversation |
| Enter | Send a message |
| Shift+Enter | New line in your message |
| Ctrl+V | Paste, also images and screenshots |
| F1 | Help for the screen that is open |
| Enter on an approval card | Allow |
| Esc on an approval card | Deny |

Take a screenshot with Windows key+Shift+S, then paste it into the chat with Ctrl+V.
