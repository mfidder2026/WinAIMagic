When **Web** is on below the input field, the model searches the web itself (`web_search`) and reads pages (`fetch_url`). You see every step, and the sources below the answer.

## Search engine
- By default: **DuckDuckGo**, without an account.
- Or **Brave Search**, with your own API key: Settings → Chat → Web search.
- When a search engine refuses for a while, another takes over and the app says so.

## Privacy
Only the search query and the addresses of the pages go to the internet. The conversation itself stays on this PC.

> A web page can contain text that tries to steer the model. After reading the web the model therefore learns nothing for WINAIMAGIC.md, and a system change gets an extra warning.
